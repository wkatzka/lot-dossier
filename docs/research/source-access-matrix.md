## Named blocking dependencies

1. Obtain actual recorded instruments and a sufficiently complete dated search, including parent parcels, amendments/releases and mineral reservations. Current public endpoints expose references, not the required chain.
2. Recover and verify pilot boundary/constraint geometry from original survey documents with source control and accuracy. Current GIS geometry layers have no pilot coverage; the available PDF is not automatically registered.
3. Establish a permitted, verified local closed-sale comparison set and independent holdout observations. Public assessor/auction evidence inspected so far is insufficient. No validated market value is released.
4. Provision private cloud storage/authentication and apply the supplied RLS schema before live cloud access tests. No cloud account/database has been provisioned by this implementation.
5. Configure authorized city portal/API access before automatic filing, monitoring or correspondence can run.

## Survey follow-up

The original vector PDF was inspected beyond the public GIS coverage gap. It contains named CAD drawing layers; the new extractor retained 3,619 paths across five pages for the pilot. These are PDF drawing paths (including triangulated strokes), not a ready-made surveyed lot polygon. Direct polygonization did not produce a closed polygon around the target lot label, so that attempt was rejected rather than used as a boundary.

The county section-corner service returned 20 nearby monuments. Three printed references matched unique public monument records and candidate drawing symbols. A two-control-point similarity fit passed an independent third-point check at approximately 0.088 m. The public records carry a `1M` quality label and old/unspecified condition dates. The alignment remains an unreviewed candidate, not verified centimetre accuracy. The UI may display a clearly marked candidate drawing overlay; it does not use it to clear a pool placement.
